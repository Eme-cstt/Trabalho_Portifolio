#  Meu Portfólio Pessoal - Emerson Castro

Bem-vindo ao repositório do meu portfólio web! Este projeto foi desenvolvido para centralizar e apresentar minha jornada acadêmica, experiências profissionais no setor de Tecnologia da Informação e os principais projetos práticos que venho desenvolvendo como **Desenvolvedor Full Stack**.

O site conta com um design moderno, focado na experiência do usuário, alta performance visual e suporte nativo a temas personalizados.

---

##  Tecnologias Utilizadas

Para a construção dessa aplicação, foquei em utilizar a base do ecossistema Web de forma pura e performática:

* **HTML5:** Estruturação semântica e acessível de todas as seções.
* **CSS3 Avançado:** Uso de CSS Variables, Flexbox, Grid Layout, animações de transição e total responsividade (Mobile First).
* **JavaScript:** Manipulação dinâmica do DOM, persistência de preferências do usuário com `localStorage` e lógica para alternância de temas.
* **Google Fonts:** Integração das fontes *Inter*, *Montserrat* e *JetBrains Mono* para uma identidade visual *developer-oriented*.

---

## Funcionalidades em Destaque

* ** Dark/Light Mode Nativo:** Sistema inteligente que alterna as cores da aplicação através de variáveis CSS, salvando a escolha do usuário diretamente no navegador (`localStorage`).
* ** Totalmente Responsivo:** Layout projetado para se adaptar perfeitamente desde telas de smartphones até monitores ultra-wide.
* ** Linha do Tempo Dinâmica:** Apresentação elegante da minha jornada acadêmica e profissional utilizando recursos visuais modernos de linha do tempo (*timeline*).
* ** Seção Interativa Extra-Código:** Espaço dinâmico configurado via CSS/JS para exibir hobbies e interações personalizadas da minha vida pessoal.

---

##  Estrutura de Seções do Portfólio

1.  **Home / Inicial:** Apresentação principal, destacando meu foco como Full Stack Developer e tempo de experiência na área.
2.  **Minha Jornada (Formação):** Detalhes da graduação em Ciência da Computação, Ensino Médio Técnico e certificações relevantes (AWS, Cisco, LGPD).
3.  **Trajetória Profissional:** Exposição das minhas atuações no mercado (Suporte Técnico, Infraestrutura de TI e migração de sistemas corporativos).
4.  **Projetos em Destaque:** Vitrine de aplicações reais com links diretos, englobando integrações com APIs (OpenWeather), Visão Computacional (OCR com OpenCV) e APIs RESTful (Node.js/Express).
5.  **Contato:** Canal direto para propostas e conexões profissionais.
